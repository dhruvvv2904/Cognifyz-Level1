# Cognifyz-Level1
Level 1 tasks completed during Data Analyst Internship at Cognifyz Technologies

---

## 📊 Tasks Implemented

**1️⃣ Top Cuisines Analysis**
- Identified the **top 3 most common cuisines**.
- Calculated **percentage of restaurants** for each cuisine.
- Visualized using **bar charts**.

**2️⃣ City Analysis**
- Determined **cities with the highest number of restaurants**.
- Calculated **average ratings** per city.
- Identified **city with the highest average rating**.
- Visualized results with **bar charts**.

**3️⃣ Price Range Distribution**
- Analyzed **restaurant price range categories**.
- Calculated **percentage distribution** for each price range.
- Created **histogram/bar chart** for visualization.

**4️⃣ Online Delivery Analysis**
- Determined **percentage of restaurants offering online delivery**.
- Compared **average ratings** of restaurants with vs without online delivery.
- Visualized comparisons with **bar charts**.
